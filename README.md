# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas ni instalaciones!** Todo el aprendizaje se realiza directamente desde el navegador web.

- **Duración total:** ~60 minutos (6 lecciones cortas).
- **Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa en programación.
- **Prerrequisitos:** Ninguno.
- **Herramientas necesarias:** Un navegador web (Chrome, Firefox, Safari o Edge).
- **Repositorio de código fuente:** [https://github.com/dymbia-aplicaciones-web/webdev-course-dymbia](https://github.com/dymbia-aplicaciones-web/webdev-course-dymbia)



## Secuencia de las Lecciones

### Lección 1: ¿Qué es el Desarrollo Web y tu Primera Etiqueta? (5 minutos)
- **Descripción:** Descubre cómo funciona la web y escribe tus primeras etiquetas HTML (`<h1>` y `<h2>`) en un editor en línea.
- **Enlace al video:** [Ver Lección 1 en YouTube](https://www.youtube.com/watch?v=example-link1)
- **Guía pedagógica:** [scripts/leccion-01.md](scripts/leccion-01.md)
- **Consejos clave:** HTML le da estructura al sitio (esqueleto) y CSS define su estilo (decoración).
- **Empieza a programar:** [CodePen Starter](https://codepen.io/pen/?template=your-starter-01)  *¡No requiere registro!*

### Lección 2: Estructura HTML Básica, Atributos y Párrafos (10 minutos)
- **Descripción:** Aprende la anatomía de una página web (`<html>`, `<head>`, `<body>`), usa atributos como `lang="es"` e integra un párrafo de biografía.
- **Enlace al video:** [Ver Lección 2 en YouTube](https://www.youtube.com/watch?v=example-link2)
- **Guía pedagógica:** [scripts/leccion-02.md](scripts/leccion-02.md)
- **Consejos clave:** Lo invisible va en el `<head>`; lo visible va en el `<body>`.
- **Práctica:** [CodePen Starter](https://codepen.io/pen/?template=your-starter-02)

### Lección 3: Listas, Imágenes y Enlaces Interactivos (8 minutos)
- **Descripción:** Enriquece tu perfil agregando una foto de avatar (`<img>`), una lista de pasatiempos (`<ul>`, `<li>`) y un enlace externo (`<a>`).
- **Enlace al video:** [Ver Lección 3 en YouTube](https://www.youtube.com/watch?v=example-link3)
- **Guía pedagógica:** [scripts/leccion-03.md](scripts/leccion-03.md)
- **Consejos clave:** La etiqueta `<img>` no necesita cierre; siempre usa el atributo `alt` por accesibilidad.
- **Práctica:** [JSFiddle Starter](https://jsfiddle.net/your-fiddle-id)

### Lección 4: Introducción a CSS (Selectores y Estilos Básicos) (12 minutos)
- **Descripción:** Conecta una hoja de estilo externa (`style.css`), cambia fuentes, colores de fondo y transforma tu avatar en una foto circular.
- **Enlace al video:** [Ver Lección 4 en YouTube](https://www.youtube.com/watch?v=example-link4)
- **Guía pedagógica:** [scripts/leccion-04.md](scripts/leccion-04.md)
- **Consejos clave:** Vincular el CSS en el `<head>` mediante `<link rel="stylesheet" href="style.css">`.
- **Práctica:** [CodePen Starter](https://codepen.io/pen/?template=your-starter-04)

### Lección 5: Proyecto Final: Mi Tarjeta de Perfil Digital (15 minutos)
- **Descripción:** Utiliza el Modelo de Caja (`margin`, `padding`, `border`) con contenedores `<div>` y clases CSS para construir una tarjeta flotante y centrada.
- **Enlace al video:** [Ver Lección 5 en YouTube](https://www.youtube.com/watch?v=example-link5)
- **Guía pedagógica:** [scripts/leccion-05.md](scripts/leccion-05.md)
- **Consejos clave:** `margin` espacio exterior, `padding` espacio interior.
- **Proyecto Final:** [Replit Starter](https://replit.com/@your-final-project)  *¡Guarda y comparte!*

### Lección 6: Errores Comunes, Código Limpio y Próximos Pasos (10 minutos)
- **Descripción:** Aprende a diagnosticar fallas en HTML/CSS, aplica sangría (indentación) limpia y valida tu código con la W3C.
- **Enlace al video:** [Ver Lección 6 en YouTube](https://www.youtube.com/watch?v=example-link6)
- **Guía pedagógica:** [scripts/leccion-06.md](scripts/leccion-06.md)
- **Consejos clave:** Cierra todas las etiquetas y aplica siempre 2 espacios de sangría.
- **Comparte tu trabajo:** [Formulario de Entrega](https://forms.gle/your-form)
